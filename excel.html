Data Cleaning in Excel

Bike Sales Analysis

In this project, a dataset of bikes buyers contains approximately 1000+ customer records was used to analyse purchase patterns among different demographic and socioeconomic groups. The data consist of following details for analysis purpose.

  • Demographics: Gender, Marital status, Age, Education and Occupation.
  • Socioeconomic: Income, Home ownership, Number of children.
  • Lifestyle: Commute distancce, Region.
  • Variable: Purchased bike (Yes/No)
    • The raw dataset was cleaned, organized and transformed into an interactive dashboard for better visualization.

    Data Cleaning

    1. Removing duplicates and blank rows.
    2. Converting text to proper case - 'F' and 'M' in gender category, replace them to 'Female' and 'Male'. While in marital status 'M' and 'S' is replace to 'Married' and 'Single'.
    3. Updating currency format to standardised data.

    Data Transformation

    1. Using IFS statement to create age range and grouping them into 'Youth', 'Adult', 'Old'.
    2. Standardising categorical data (ex: "Yes/No" responses)

    Pivot Tables and Charts

    1. Creating pivot tables to summarise relationship between Income vs Bike Purchase, Commute Distance vs Bike Purchase, Age Range vs Bike Purchase.
    2. Inserting visual charts for pivot table summaries.

    Dashboard visualization

    1. Creating interactive dashboard with slicers linking to chart for dynamic filtering.
    2. Formatting dashboard layout with consistent colours and fonts.
